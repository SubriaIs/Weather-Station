# Weather-Station
## Views
### Current Weather information of Tampere:
Displays real-time weather information including temperature, feels-like temperature, conditions, wind speed, and humidity
![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Tampere%20weather.png)

### Latest 30 measurements:
Displays the latest 30 environmental data points in a table format. This real-time weather data collected from Tampere University Of Applied Science sensors. Key metrics include humidity, wind speed, rainfall, wind direction, temperature, and light levels.
![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Latest%2030%20measurement.png)


### Latest 20 temperature measurements:
Shows the most recent 20 temperature measurements in a table. This real-time weather data collected from Tampere University Of Applied Science sensors. Users can search for temperature information across different time frames: recent, 24 hours, 48 hours, 72 hours, or a week. Also can search by date. Features a bar chart visualization to help users easily interpret temperature trends.
![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/latest%2020%20temperature%20measurement.png)

![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Temperature%20Bar.png)


### Latest 20 wind speed measurements:
Displays the latest 20 wind speed measurements in a table. This real-time weather data collected from Tampere University Of Applied Science sensors. This view includes a search option to filter wind speed information for recent, 24 hours, 48 hours, 72 hours, or a week. Also can search by date.Provides a bar chart for visualizing wind speed data over time.
![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Latest%2020%20wind%20speed%20measurement.png)

![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Wind%20speed%20bar.png)


### Time and Measurement (UI):
Offers a table view for different measurement types (rain, wind speed, light, wind direction, temperature) with selectable time intervals (now, 24 hours, 48 hours, 72 hours, or a week).Includes line chart visualizations to represent measurements over time, providing clear insights into trends and variations. This real-time weather data collected from Tampere University Of Applied Science sensors.
![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Time%20and%20measurement.png)

![Application Screenshot](https://github.com/SubriaIs/Weather-Station/blob/main/Line%20chart.png)

## Features

**Current Tampere Weather Date:**  
Display current weather information of Tampere city.

**Comprehensive Data Display:**  
View detailed environmental data and temperature measurements in tabular formats for easy comparison.

**Customizable Search:**  
Filter data by various time intervals and dates to obtain relevant historical information.

**Visual Analytics:**  
Utilize bar and line charts for intuitive visualizations of temperature, wind speed, and other measurements.



## Getting Started

To run this application, follow these steps:
Clone the Repository and open `index.html` in the browser.
